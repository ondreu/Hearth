**Hearth 把您的 Obsidian 仓库变成一个温暖的首页。** 一个快速的模糊搜索栏、
便捷的文件类型筛选，以及一片可自由排布的实时小组件网格 —— 笔记、任务、看板、
日历、网页、统计、时钟和启动器 —— 桌面端和移动端皆可使用。

可以把它看作新标签页面板、起始页与命令启动器三合一。

- 🔍 **搜索一切** —— 模糊搜索、全文、标签、frontmatter 与命令
- 🧩 **35+ 种卡片** —— 嵌入、任务、日历、Dataview、Git、Jira、Operon 等等
- 🔌 **25 项集成** —— 插件启用后自动识别
- 🎛️ **自由布局** —— 卡片可任意拖动、缩放与吸附
- 🪟 **毛玻璃** —— 每张卡片可单独设置不透明度、模糊、颜色和圆角
- 🗂️ **多个面板** —— 一次点击或一个快捷键即可切换
- 🪄 **插件视图面板** —— 把整个面板交给某个插件的视图
- 📱 **手机可用** —— 面板会堆叠为可读的单列

## 快速开始

1. 从 Obsidian 的社区插件浏览器安装 **Hearth** —— 或者把 `main.js`、
   `manifest.json` 和 `styles.css` 放进
   `<vault>/.obsidian/plugins/hearth/` 并启用它。
2. Hearth 会在启动时打开，并替换空白的新标签页（两者都可在
   **设置 → Hearth** 中切换）。
3. 随时可以通过侧边栏的 **home** 图标或 **打开主控面板** 命令打开它。
4. 点击 **排列**（右上角），即可直接在面板上添加、移动、缩放和配置卡片。

## 设置向导

全新安装时，Hearth 会主动为您搭建第一个面板。它会问几个问题 —— 标题、外观、
您用仓库做什么 —— 然后根据答案排布出一个面板，而不是把您丢在一片通用的起始网格上。

它还会**看看您已经有什么**。下面每个已安装并启用的插件都会被提出，
并说明接受它会带来的那一件事：

| 已发现 | Hearth 会怎么用它 |
| --- | --- |
| **TaskNotes** | 添加一张以 TaskNotes 为来源的任务卡片，使用 TaskNotes *自己的*字段名和完成状态 |
| **Kanban** | 添加一张任务卡片，把看板显示为可拖动的列 |
| **Dataview** / **Datacore** | 添加一张卡片，并预置一条可编辑的查询 |
| **Templater** | 添加一个启动台，为您已有的每个模板配一个按钮 |
| **Git** | 添加一张带状态、提交和同步的 Git 卡片 |
| **Operon** | 添加一张 Operon 任务卡片（仅桌面端 —— Operon 仍会要求您批准 Hearth） |
| **Bases** | 嵌入仓库中的一个 base |
| **日记** / **书签** | 添加对应的卡片 |

TaskNotes 这一项值得特别一提：它的字段名可由用户重映射、状态可由用户自定义，
因此 Hearth 会从该插件读取这些设置并复制到它搭建的卡片上。
即使您把 `due` 改名为 `deadline`，任务卡片在首次渲染时也能正常工作。

向导只提供上面这些集成；[集成](#集成)中的其他一切都通过 **添加卡片**
选择器手动加入。

**向导只会写入它所搭建的那个面板。** 标题、图标、强调色、卡片表面、间距和背景
都会作为*按面板的覆盖设置*落在那一个面板上，而 TaskNotes 的字段映射则落在
任务卡片本身 —— 因此您的仓库全局设置，以及您已有的其他每个面板，
在一次设置运行前后完全一致。这也是它不再询问那些只能全局生效的事项的原因
（Hearth 是否在启动时打开、笔记在哪里打开、使用哪个搜索引擎、显示谁的文件图标）：
这些都在 **设置 → Hearth** 中，每项一个开关，按设计对所有内容生效。

最后一步会在写入任何内容之前预览面板 —— 一张按比例的示意图，加上每张卡片
及其入选理由的列表。在您按下 **搭建我的面板** 之前，什么都不会被应用。

您随时可以从 **设置 → Hearth → 关于 → 搭建一个面板** 或 **设置 Hearth**
命令再次运行它。以这种方式运行时它*总是*添加一个新面板：
您已有的每个面板都保持原样。

## 搜索

搜索框以键盘操作为先，有四种一目了然的模式：

| 前缀 | 模式 | 匹配内容 |
| --- | --- | --- |
| *（无）* | 模糊 + 全文 | 文件名、标签、属性和笔记正文 |
| `#` | 标签 | 仓库标签，并显示匹配到哪个标签 |
| `key:value` | Frontmatter | 属性匹配的笔记 |
| `>` | 命令 | 任何已注册的命令，按名称运行 |

- **自动检测的筛选** —— 根据仓库中实际存在的内容构建的文件类型标签
  （笔记、图片、视频、白板、bases、Excalidraw…）。点击其中一个即可列出该类条目；
  不需要的可以隐藏。
- **最近文件** 会在搜索框为空且聚焦时出现。
- **新建笔记** 按钮会在默认位置创建笔记 —— 如果您更愿意，也可以把查询
  发送给 DuckDuckGo。
- **Omnisearch 引擎** *（可选）* —— 在 **设置 → 外观 → 搜索引擎** 下把内置引擎
  换成 [Omnisearch](https://github.com/scambier/obsidian-omnisearch)。
- **隐藏它** —— **设置 → 外观 → 主页 → 显示搜索区域** 可在仓库范围内关闭整个区域，
  而每个面板的 **搜索可见性** 既可以跟随该默认值，也可以覆盖它，
  从而仅在该面板上显示或隐藏这一区域。

## 卡片

从 **排列** 工具栏添加卡片；每张卡片都从卡片本身进行配置（标题、内容、颜色、
尺寸、不透明度、模糊）。**添加卡片** 会打开一个可搜索的选择器 —— 输入以匹配
卡片的名称或描述，或按下面的分类浏览。依赖社区插件的卡片始终会被列出，
在插件缺失时标注 *需要 Dataview*（或 Git、Operon…），并提供一键跳转安装。
如果您想要的卡片还不存在，可以点击侧栏底部的 **申请一种卡片**，
它会打开一个预填好的 GitHub issue 或邮件。

### 计划

| 卡片 | 显示内容 | 需要 |
| --- | --- | --- |
| **任务** | Markdown 复选框、TaskNotes 任务笔记或一个 [Kanban](https://github.com/obsidian-community/obsidian-kanban) 看板 —— 以列表或可拖放的看板呈现 | — |
| **日历** | 基于同样来源的月、周、日和列表视图，带可滚动的时间网格、重叠事件分列和全天事件区 | — |
| **迷你日历** | 月视图网格或日程，为已有笔记显示圆点，支持 ISO 周数和编辑热力图 | 日记（核心） |
| **时钟与问候** | 数字或指针表盘、自定义日期格式、可选的俏皮问候语 | — |

**任务卡片内部**

- **Kanban 写回** —— 拖放会以 Kanban 自己的格式写入，因此该笔记在 Kanban
  插件中仍可编辑。
- **日期与优先级** —— 完整支持
  [obsidian-tasks](https://github.com/obsidian-tasks-group/obsidian-tasks)
  的标记（🔺⏫🔼🔽⏬ 🔁 🛫 ⏳ 📅 ✅）、相对标签（“今天”、“下周五”）、
  自然语言输入（`📅 in 3 days`），以及重复任务的按次完成。
- **排序与筛选** —— 智能链（到期 → 计划 → 优先级 → 创建时间）或自定义多规则排序，
  可按列表和按看板列分别设定。
- **自定义任务字段** *（需开启）* —— 为字段命名、选择呈现方式（标签、圆点、文本、
  行染色或光晕），并把任何 frontmatter 或内置键映射为标签和颜色。
  点击某个值即可修改它。
- **快速查看** —— 点击任务会打开一个紧凑弹窗，其中的元数据和描述可编辑，
  无需跳进笔记。

**日历内部** —— 两者默认都跟随您所在区域的每周起始日和时制；每周起始日、
隐藏周末、周数、绘制的时段和每小时高度都可由您设定。迷你日历还可以订阅外部
**ICS/iCal** 源、读取 **TaskNotes**（计划、到期、重复、时间块）和 **Operon**
的到期日，并为任意事件创建笔记，通过 ID 反向关联。

### 集成卡片

在选择器中归类为 **集成**。

| 卡片 | 显示内容 | 需要 |

| **从模板新建笔记** | 每个按钮都能从一个 Templater 模板创建笔记，文件夹和文件名格式由您指定 | [Templater](https://github.com/SilentVoid13/Templater) |

| **Git** | 分支、已暂存与已变更文件、未推送提交和最近日志，并带提交 / 同步 / 推送 / 拉取 / 暂存 / 放弃按钮以及按文件差异 | [Git](https://github.com/Vinzent03/obsidian-git) |
| **Jira 筛选器** | 来自已保存 Jira 筛选器或 JQL 搜索的事项，可按状态、负责人、优先级、类型、迭代和版本筛选 | 通过 HTTPS 访问 Jira |
| **RSS 订阅** | 来自您关注的任意 RSS 2.0 或 Atom 源的头条 | 联网 |
| **天气** | 来自 [Open-Meteo](https://open-meteo.com) 的当前天况和预报，共五种样式，最高可达铺满整屏、跟随真实天况与时段的绘制天空 —— 点击卡片可查看完整预报，精确到每小时 | 联网 |
| **Operon 任务 / 看板 / 日程 / 计时器** | 基于 [Operon](https://github.com/hasanyilmaz/operon) 自己 API 的四张卡片 —— 任务列表、流程看板、几天的日程，以及正在运行的时间追踪 | Operon（桌面端） |
| **插件视图** *（测试版）* | 在卡片中承载另一个插件的侧边面板视图（日历、大纲、标签面板、Kanban…），可选固定到某个文件 | 一个提供视图的插件 |

Templater 卡片能做到 Templater 自己的按模板命令做不到的事：同一个模板可以由
三个不同按钮写入三个不同文件夹。模板处理仍由 Templater 完成 —— 用户脚本、
`tp.system.prompt()` 对话框和 `tp.file.cursor()` 定位的行为都与从它自己的命令
调用时一致。

Git 和 Operon 都是*通过*另一个插件工作，而不是绕过它：Git 提交会走 Git 插件
自己的任务队列，因此您的远端、凭据和提交信息模板都原样适用，
而 Hearth 从不解析 Operon 的笔记。它的设置见 [Operon](#operon)，
那也是唯一需要您动手一步的集成。

### 趣味

| 卡片 | 显示内容 | 需要 |
| --- | --- | --- |
| **宠物** | 一只像素风小伙伴（猫、狗、鸟、狐狸、青蛙或软软），心情跟随您的仓库 —— 满足、开心、无聊，或在安静的一天里睡去，带绘制动画和跟随指针的眼睛。可设置夜间时段、命名、上色。不会丢失；点击它还能收获爱心 | — |

一切都是**实时的**：嵌入和可编辑的笔记会跟随仓库事件而不丢失光标位置，
数据卡片会随仓库和元数据变化重绘，网页卡片按计时器刷新。每一张会联网的卡片
都遵守 **设置 → 行为 → 禁用对外调用**。

| **搜索** | 把查询交给 Obsidian 的搜索面板以获取完整结果 |
| **文件浏览器** | 为搜索结果上的“在文件浏览器中显示”提供支持 |
| **工作区** | 打开某个面板时，它可以切换到一个已保存的工作区 |
| **录音机** | 移动端的“录音”操作按钮 |
| **任何带侧边面板的插件** | 插件视图卡片可承载任何已注册的视图 |

**外部服务** —— 通过 **行为 → 隐私与网络 → 禁用对外调用** 可一次性全部静默。

| 服务 | 使用者 | 账号 / 密钥 |
| --- | --- | --- |

| [Frankfurter](https://www.frankfurter.app/)（欧洲央行汇率） | 计算器的货币换算 | 无需 |

### Operon

这四张 Operon 卡片通过 Operon 自己的进程内开发者 API 读取数据，
因此重复规则、状态和完成判定仍由 Operon 定义。筛选项是基于 Operon 实际拥有的
内容构建的选择器 —— 流程、状态、优先级、完成情况、笔记或文本 —— 您也可以把
整个问题交给 Operon 自己的某个范围（*今天发生*、*已逾期*、*最近处理过*）。
点击任务会在准确的行上打开它的笔记。

**读取是默认，更改是选择。** 开启 *允许更改*
（**设置 → Hearth → 集成 → Operon**），看板卡片就允许您把任务拖到另一个状态列 ——
或者从该行的右键菜单中选择，因此无需鼠标也能操作 —— 并且每张卡片都会多出一个
**+**，用于在 Operon 自己设置指定的位置创建任务。Hearth 预览更改，
Operon 评定并应用它，任何超出常规的操作都会先与您确认。一次移动会带上看板绘制时
的状态，因此在过期看板上的拖动会被拒绝，而不是悄悄撤销他人的更改。
把开关保持关闭，Hearth 就只能读取。

在添加之前：

| | |
| --- | --- |
| **平台** | 仅桌面端，Obsidian 1.12.2 或更新版本 |
| **批准** | Hearth 的请求会出现在 **设置 → Operon → Core → General → Developer API Integrations** 中 —— 请在那里批准。在此之前卡片会说明它在等什么 |
| **扩大权限** | Operon 采用全有或全无的授予方式，因此开启 *允许更改* 需要重新批准 |
| **状态与总开关** | **设置 → Hearth → 集成** 会显示连接情况、请求了什么，以及如何切断它 |

## 布局

- **自由拖动与缩放** —— 卡片可移动到任何位置，并从任意边或角缩放，
  同时会磁性吸附到相邻卡片和面板边界。
- **边缘合并** —— 把两张卡片吸在一起，它们共享的边框会消失，
  这一对读起来就像一整块连续的磁贴。
- **多个面板** —— 左上角有一个 `[1] [2] [+]` 切换器。可为每个面板命名、
  指定表情或 Lucide 图标、拖动重排，并按面板覆盖全局宽度、列数、行高、
  背景和标题图标。可从 **排列** 工具栏中的 **面板设置** 打开某个面板的设置，
  或右键其切换按钮。
- **插件视图面板** —— 把某个面板的 **仪表板类型** 设为 **插件视图**，它就不再是
  卡片网格：整个面板变成某个插件的视图 —— RSS 阅读器、看板、Canvas 白板、大纲
  —— 以完整尺寸真实运行，而切换器、顶部与背景依然在它周围。于是你每天要看二十次
  的阅读器，与任务面板之间只隔一次点击，而不是一个还得找路回来的标签页。

  在面板的 **插件视图** 标签页中选择视图。列表为当前应用注册的全部视图，包括
  Obsidian 自带的文档视图（Markdown、PDF、图片、音频、视频）—— 整个面板既有空间，
  类型选择器旁边也有文件选择器，因此某个具体的笔记、绘图或 PDF 本身就可以是一个
  仪表板。你还可以隐藏所承载视图自带的面包屑标题栏，或让它获得焦点，使插件自身的
  命令与快捷键能找到它（实验性 —— 此时 Obsidian 可能会把点击打开的笔记放进它）。

  **通铺到边。** 所承载的视图占满整个窗格 —— 没有页面留白、没有卡片边框、没有工具栏
  行 —— 仅保留顶部的切换器条，面板设置齿轮位于其右端。标题与搜索出于同样的原因默认
  隐藏；这些都是普通的按面板覆盖项，可随时改回。

  **切换是即时的。** 显示其他面板时，插件视图面板仍保持加载，而不是每次重新冷启动；
  同时最多保持三个，较重的插件可在 **在后台保持运行** 中按面板关闭。该面板还会保留
  自己的卡片，改回 **卡片** 类型即可原样恢复。
- **固定卡片** —— 把某张卡片固定为在每个面板上显示，共享同一份定义和位置。
- **适应页面** —— 把面板锁定在一屏内，或让它滚动。
- **导入 / 导出** —— 把单个仪表板导出为文件，在别人的库中也呈现相同的样子
  （壁纸可选择一并打包），并用 Hearth 为你生成的匿名代号签名，别人无法冒用；
  一个开关即可把笔记路径、日历链接与位置排除在外——也可将所有面板与设置备份为 JSON。
- **仪表板画廊** —— 浏览别人发布的仪表板，按分类、搜索或评分查找，一键安装；
  在你已经用来导出的同一个对话框里发布自己的作品，发布时会移除你的路径与私有
  订阅源，并为文件签名，别人无法用你的 handle 发布。你收到的赞会累计在个人页上。
  打开画廊之前不会拉取任何内容，发布之前也不会发送任何内容；在设置中清空地址即可
  彻底关闭画廊，并且会一直保持关闭。任何人也都可以[自建一个](docs/gallery-hosting.md)：
  服务端就在本仓库中，一条 Docker 命令即可启动。

## 外观

- **背景** —— 纯色、仓库图片、网址，或**实时天气天空**：面板的背景会变成
  天气卡片艺术风格所绘制的天空，铺满整个窗口，并跟随您所选地点的真实天况与时段。
  也可以固定一种天空 —— 晴朗的夜、雪、雷 —— 不论外面天气如何都保持它，
  这样无需位置信息，也永不联网。全部都支持不透明度和模糊。
  默认自带一张柔和的氛围壁纸。
- **横幅或完整背景** —— 同一张背景两种穿法：铺满整个视图，或作为面板顶部的
  **横幅**，就像笔记上方的封面图，下方的卡片使用您主题自身的表面。可设置高度、
  让下边缘淡入页面，并选择它是与内容对齐还是横贯窗口两端 ——
  每一项都是按面板的覆盖设置，因此一个面板可以把仓库背景显示为横幅，
  而下一个面板仍把它当作壁纸。
- **毛玻璃** —— 卡片不透明度和背景模糊有三个层级（全局 → 按面板 → 按卡片）。
  合并的卡片会作为一整块无缝表面进行模糊。
- **卡片圆角半径** —— 从默认的 14 px 一直到锐利的 0 px。
- **按卡片配色** —— 可为任意卡片设置强调色和背景色调。
- **面板顶部的标题、标题图标与紧凑间距**。
- **专属的搜索行与界面元素** —— 每个仪表板都可以设置自己的搜索占位文字、搜索框旁的按钮
  （或不显示）、自己的筛选标签、变窄时是否堆叠为单列、“排列”按钮与切换器是始终可见还是
  悬停时淡入，以及绘制的天空是否飘动。这些默认跟随全库设置，直到面板另行指定；导出面板时
  也会一并带走。
- **一个标题图标，四种设置方式** —— 面板标题旁的标识可以是 **Lucide 图标**
  （可在选择器中搜索，而不必凭记忆输入）、**表情或一两个字符**、
  **仓库中图片的路径**，或**网络图片的网址**。每个面板都可以覆盖它；
  留空则保持 Hearth 水晶图标不变。Hearth 的**标签页和侧边栏**按钮
  则有自己的 Lucide 图标设置。

## 移动端

Hearth 的面板采用自由布局 —— 卡片停在你放下的位置，宽度是面板宽度的一个比例。
当宽度低于约 **600px** 时，这种布局便失去了意义，因此面板会**重排为单列通栏**，
自上而下，顺序与桌面端面板的阅读顺序一致。你的布局绝不会被改写：同一个面板，
在手机上是启动器，在显示器上仍是一整墙卡片。

判断依据是**实际测得的面板宽度**，而非平台 —— 因此桌面端的窄窗格同样适用，
你也可以把窗格拖窄来查看手机布局。

- **堆叠单列** —— 卡片通栏，每行一张。可在 **设置 → Hearth → 移动端**
  中关闭，以保留自由布局。
- **逐卡片覆盖** —— 在卡片设置中（布局 → *窄屏面板上*）：**隐藏**该卡片、
  指定它在列中的**位置**、设置**高度**，或让它**默认折叠**为标题行，
  仅在点击时才构建 —— 于是高开销的卡片在被打开前只占一行。
- **手机预览** —— 点击 **排列 → 以手机宽度预览**，无需手机即可搭建并检查
  手机面板，并绘制出手机外框，让比例一目了然。堆叠状态下，拖动卡片下边缘即可
  设置高度，并可用标题栏中的上移 / 下移按钮调整顺序。
- **通栏到边** —— 去掉两侧留白，但保留安全区内边距；筛选按钮与搜索结果
  在该宽度下放大为 44px 的点按目标。
- **通栏搜索** —— 筛选按钮和结果列表占满整屏，而不只是搜索框那一份宽度；
  搜索框旁的按钮收为图标。
- **独立的性能档位** —— 移动端默认为*均衡*；桌面端档位单独保存，不受影响。
- **独立的设置分类** —— 以上全部位于 **设置 → Hearth → 移动端**。
- **移动模式** —— 依然保留：可选的纯搜索启动器，如果你在手机上只需要这些。
- **操作栏** —— 搜索框下方的一排按钮（默认为新建笔记、新建绘图、录音、
  打开日记），每个都可替换为任意命令。
- **感知键盘** —— 可见区域会跟随屏幕键盘变化。

## 设置与快捷键

所有设置都在 **设置 → Hearth** 下，按分类栏分组：
**外观**、**搜索**、**面板**、**行为**（启动、新标签页、笔记打开位置、
移动端、隐私）、**集成**、**备份** 和 **关于**。
每张卡片的设置在排列模式下从卡片本身编辑。

可在 **设置 → 快捷键** 中绑定：

- **打开主控面板**
- **切换到面板 1…9**
- **切换到下一个 / 上一个面板**

在搜索框中：`↑`/`↓` 移动，`Enter` 打开，`Esc` 关闭。
