# Power benchmark harness

Renders Hearth's *own* drawing code — `src/sky.ts` and `src/grid.ts`, unmodified,
behind a shim for Obsidian's DOM helpers — in headless Chromium at DPR 2, and
measures what it costs. Written for
[`../macos-power-investigation.md`](../macos-power-investigation.md); kept so the
numbers there can be re-checked after a change.

## Running

Needs Chromium via Playwright. It is normally a global install in CI images
rather than a devDependency here; `harness.mjs` looks in the usual places and
says so if it can't find one.

```sh
node docs/performance/bench/build.mjs      # bundle entry.ts (styles.css is linked directly)
node docs/performance/bench/micro.mjs      # start here — the controlled comparison
node docs/performance/bench/bench.mjs      # whole-board scenarios
node docs/performance/bench/hidden.mjs     # cost when the board isn't visible
node docs/performance/bench/gpu.mjs        # browser-level trace, GPU process included
```

`WINDOW_MS` sets the measurement window (default 5000–6000ms); `bench.mjs` also
takes `REPEATS` and reports the median run.

## What each script answers

| Script | Question |
|---|---|
| `micro.mjs` | What does each animation *shape* cost, against the same motion on a plain HTML element? |
| `bench.mjs` | What does a realistic 8-card board cost, wallpaper and frost included? |
| `hidden.mjs` | Does it still cost anything when the board isn't on screen? |
| `gpu.mjs` | Is the compositor producing frames, and how many? |

## Reading the output

A compositor-driven animation costs the main thread **nothing**: zero style
recalcs, zero layouts, zero paints. Any figure above zero in those columns is
main-thread work that a correctly-composited animation would not have done —
that, not the absolute milliseconds, is the signal. Absolute times depend on the
host; the ratios and the zeros are what transfer.

`micro.mjs` is the load-bearing script because every case has a control beside
it. Start there.

## Caveats

- Linux, no GPU: blur and raster fall to a software rasterizer, so this harness
  cannot price `backdrop-filter` the way a Mac would. Main-thread figures are
  unaffected.
- `bundle.js` is generated by `build.mjs` and is gitignored. The pages link
  `styles.css` from the repo root directly rather than copying it — an earlier
  version copied it, and a stale copy silently measured the wrong CSS.
